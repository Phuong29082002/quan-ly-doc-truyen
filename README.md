# Hệ thống Quản lý Đọc truyện

Đồ án Công nghệ Phần mềm Nâng cao – HUFLIT

## Công nghệ
- Backend: ASP.NET Core Web API (.NET 10), EF Core
- Web: React + TypeScript + Vite + Tailwind CSS
- Mobile: Android (Kotlin, Jetpack Compose)
- CSDL: SQL Server

## Cấu trúc
- backend/ : Web API
- web/ : giao diện web
- mobile/ : ứng dụng Android
- database/ : script SQL
- docs/ : tài liệu phân tích thiết kế
